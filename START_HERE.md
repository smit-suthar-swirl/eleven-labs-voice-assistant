## 📱 Embed on Your Site

### Button Mode
```html
<script src="http://localhost:3000/client/byd-voice-assistant.js"></script>
<script>
  BYDVoiceAssistant.init({
    mode: 'button',
    primaryColor: '#d32f2f',
    position: 'bottom-right'
  });
</script>
```

### Modal Mode
```html
<script src="http://localhost:3000/client/byd-voice-assistant.js"></script>
<script>
  BYDVoiceAssistant.init({
    mode: 'modal',
    primaryColor: '#d32f2f'
  });
</script>

<button onclick="BYDVoiceAssistant.openModal()">
  🎤 Talk to Assistant
</button>
```

## 💡 Tips

### First Time Using?
1. Grant microphone permission
2. Speak clearly
3. Wait 2-3 seconds for response
4. Try interrupting (speak while it talks)

### Modal Mode Tips
1. Click suggestion pills for quick questions
2. Watch the live transcript
3. Use clear button to reset
4. See animated waveform while speaking

### Button Mode Tips
1. Button pulses when listening
2. Spins when processing
3. Waveform when speaking
4. Click again to stop
